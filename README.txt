## Folder structure
- `index.html` — website
- `style.css` — design and responsive layout
- `assets/goshen-store.jpg` — supplied store image
- `README.txt` — instructions

## How to add your own images
1. Put the new image inside the `assets` folder.
2. Open `index.html`.
3. Find a gallery card such as:
   `<img src="assets/goshen-store.jpg" alt="...">`
4. Change the filename, for example:
   `<img src="assets/phone-products.jpg" alt="Phones and accessories">`
5. Save and refresh the website.

The placeholder cards in the Gallery section are intentionally included so you can replace them with real product/store photos later.

## Run it
Double-click `index.html` to preview it in a browser. No server is required.

## Before making the real website
Confirm the exact services, WhatsApp number, social media links, logo, business description, product categories, and Google Maps location with the business owner.
